# Modern-Login-Page
Simple Modern Login Page


A modern, animated login interface built using pure HTML, CSS, and JavaScript — no external frameworks required.
It features a sleek glassmorphism design, smooth entrance animations, floating background shapes, and simulated login functionality.

🚀 Features

✅ Glassmorphism UI – Transparent card with blur and light reflections
✅ Animated Background – Floating abstract shapes for a dynamic look
✅ Smooth Transitions – Slide, fade, and hover animations throughout
✅ Responsive Design – Fully functional on desktop and mobile
✅ Simulated Login Flow – Mimics authentication and displays success alerts
✅ Social Login Buttons – Google, GitHub, and Microsoft placeholders

🧠 Technologies Used

HTML5 – Semantic structure

CSS3 – Custom animations, gradients, and responsive design

Vanilla JavaScript (ES6) – Form handling and interactions

⚙️ Setup Instructions

Clone this repository

git clone https://github.com/your-username/modern-login.git
cd modern-login


Open in your browser
Simply open the index.html file in your favorite web browser.

💡 How It Works

The login form collects the user’s email and password.

On submission, a loading animation appears for 2 seconds (simulating an API call).

Afterward, a success message displays with the entered email.

Input fields animate slightly on focus for an interactive feel.

“Social login” buttons currently show an alert (you can connect them to real auth later).

📱 Responsive Design

The layout automatically adjusts for smaller screens:

Reduced padding

Softer background opacity

Scalable text and buttons

🧩 Customization

You can easily customize:

🎨 Colors – Update the gradient in body { background: linear-gradient(...); }

🖋️ Font Family – Change from 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif

💫 Animations – Modify or create new keyframes for a unique style
